# DUAL TETRIS — Онлайн-дуэль (Web MVP)

Веб-игра для двух игроков по сети (на мобильных телефонах и десктопе). Поля расположены друг напротив друга: соперник сверху, ты снизу. Собрал линию — выстрелил волной, которая разрушает ряды соперника, снимает HP и накладывает эффект доминирующего цвета линии.

## Структура монорепозитория

- `packages/core` — детерминированное ядро правил (3.1–3.5 ТЗ), Mulberry32 PRNG, единый конфиг баланса и свайпов (`DEFAULT_CONFIG`), Zod-схемы протокола v1 и серверный бот.
- `apps/server` — авторитетный Node.js + WebSocket (`ws`) сервер (тик 30 Гц, снапшоты 15 Гц, комнаты `/r/ABCDE`, пауза и переподключение 30 с, лимит ввода, раздача статики и `/health`).
- `apps/web` — мобильный и десктопный клиент на Vite + Canvas 2D с клиентским предсказанием активной фигуры, интерполяцией волн, свайпами, звуком и вибрацией.
- `tests/` — модульные тесты ядра (`tests/core.test.ts`), интеграционные и нагрузочные тесты на 50 одновременных матчей (`tests/integration.test.ts`).

## Быстрый запуск (чтобы поиграть с телефона по Wi-Fi или в браузере)

1. Установить зависимости и собрать веб-клиент:
   ```bash
   npm install
   npm run build
   ```
2. Запустить единый сервер (раздаёт веб-клиент и WebSocket на порту `3000`):
   ```bash
   npm start
   ```
3. В консоли появится локальный адрес и адрес в домашней Wi-Fi сети, например:
   - `http://localhost:3000`
   - `http://192.168.1.X:3000` (откройте его на телефонах в одной Wi-Fi сети, нажмите **«Создать комнату»** и отправьте ссылку `/r/ABCDE` жене!).

## Запуск в Docker / деплой (Render, Fly.io, Railway)

```bash
docker build -t dual-tetris .
docker run -p 3000:3000 dual-tetris
```
Проверка состояния сервиса: `GET /health`.
